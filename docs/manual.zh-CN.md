# cocopit(可可坑)用户手册

[English](manual.md)

cocopit 读取 Claude Code 已经在写的文件(`~/.claude/`),把它们变成可浏览、可搜索的控制台。本手册逐页说明,最后讲远程部署与恢复。

## 仪表盘

落地页。一切都跟随右上角的范围选择(7 天/30 天/90 天/全部),并按**你浏览器的时区**分桶。

- **配额条**——每个已登录订阅账号的 5 小时/每周窗口用量与重置时间。与 Claude Code 里 `/usage` 同源,约 3 分钟刷新一次。
- **统计卡**——API 等价费用(这些用量按 API 按量计费价折算的金额——是**参考数字**,不是订阅实际扣费)、输出/输入 tokens、缓存读取、缓存节省。
  - *命中率*把缓存写入算作未命中——写入的 token 是按溢价新鲜处理的,假装它不存在只会虚高数字。
  - *缓存节省*是净额:读取折扣减去 1.25×/2× 的写入溢价。
- **每日费用、按模型、Top 项目、按账号、活跃热力图**——钱和时间花在哪里。
- **价目校准**——把你的价目表与 Claude Code 自己记录的 `costUSD` 对照,标出落在合理区间之外的行。未定价模型(通常是第三方端点)在横幅里列出;想计入费用就去配置页加价目。

## 账号

一张卡一个账号,两种类型:

- **订阅**——真实的 `claude /login` 账号。非默认账号各自拥有 `~/.claude-profiles/<id>` 下的独立 `CLAUDE_CONFIG_DIR`,登录互不冲突。建好账号后复制它给出的登录命令,在你自己的终端里执行;数秒内卡片就会检测到登录。
- **API**——官方 API 或任意兼容端点的 Key(可配 Base URL、模型覆盖)。无登录流程。

卡片显示登录邮箱、套餐、订阅时间、组织——订阅账号还有实时**配额条**。配额查询背后的 OAuth 令牌在服务端读取(macOS 钥匙串;Linux/Windows 为 `<配置目录>/.credentials.json`),只用于一次 HTTPS 调用,永不发给浏览器。显示"令牌已过期"时,随便跑一次 `claude` 即可——Claude Code 会自己刷新。

「设为 shell 默认」写入 `~/.cocopit/current-profile.sh` 供你在 shell rc 里 source;只影响新终端,不影响 cocopit 自己恢复会话的方式。

删除账号只移除注册条目,登录数据目录保留在磁盘上。

## 项目

Claude Code 跑过的每个目录。可在已有项目里新开会话,也可「在新目录中开始」(目录不存在会创建,会话写下第一条记录后它就成为项目)。两条路径都可以选账号和配置方案;方案通过 `--settings` 叠加生效,不写任何 `settings.json`。

## 会话

- **搜索**——全库 trigram 全文检索,支持中文,至少 3 个字符。可按项目(从项目页进入)或按账号筛选。
- **详情**——像聊天客户端一样落在最新窗口;「加载更早」向上翻页且不丢阅读位置。大纲侧栏只列真实的用户发言(伪装成 user 记录的工具结果和 hook 噪音已被排除)。*会话内搜索*在当前记录里找文本并跳到命中处。
- **筛选**——「只看对话」隐藏一切非对话内容;思考块和元数据默认折叠;被回退过的会话会出现「显示已回退(N)」开关——回退分支带红边显示,而不是悄悄混进历史。
- **子代理**——点击任意子代理阅读其独立记录;会话生成几十个时默认只展开最贵的 6 个。
- **相关会话**——两个文件共享同一段对话记录时(resume/fork 在别处继续),互相链接,数据支持时标注方向(「继续自…」)。
- **在终端中恢复**——在服务端 tmux 终端里重开会话,可选择换一个账号(记录会以新会话 ID 复制进该账号的配置目录——Claude Code 只在自己的目录里找会话)。

## 历史

你在 Claude Code 里输入过的每条提示词(来自 `history.jsonl`),可搜索,最新在前,已知归属时可跳回所属会话。适合"我记得在哪问过这个"。

## 实时与 Web 终端

实时页列出本机正在运行的 Claude Code 进程(经 PID 校验,不只是注册表条目)和所有 cocopit 管理的 tmux 终端。

关于终端,值得知道的几件事:

- 会话跑在**服务器的 tmux 里**。关标签页、断 Wi-Fi、手机锁屏都不会杀掉它——重新打开即重新附着。连接断开时终端标题栏会出现*重新连接*按钮。
- 命令一律**服务端构造**;浏览器只发会话/项目 ID。
- 触屏设备有按键条:Esc、Tab、^C、方向键(Claude Code TUI 需要而虚拟键盘打不出的键),外加剪贴板粘贴。
- 在终端里输入 `exit` 才会真正结束底层会话。

## 配置

- **设置编辑器**——用户级(`~/.claude/settings.json`)与项目级(`.claude/settings.local.json`)。JSON 实时校验;保存前显示改了哪些键。每次写入前自动备份,CAS 戳保证并发外部修改得到明确的 409 而不是被静默覆盖。有 Claude Code 实例运行时会警告(它们退出时可能回写设置)。
- **配置方案**——把当前设置存成具名快照,之后一键套回(同样先备份、先看 diff)。方案与账号无关;新会话可以直接按方案运行而不写任何文件。
- **权限**——各作用域 allow/deny 规则的合并视图。
- **价目**——所有费用数字依据的按模型价目表。可覆盖任意价格(单独存 `~/.cocopit/pricing.user.json`,默认表保持原样),可与 LiteLLM 社区价格库对照并一键采纳差异。改价会触发全量重算——五十万条事件远不到一分钟。
- **MCP**——项目级 `.mcp.json` 的只读视图。

## 扩展

按账号分组展示都有什么在扩展 Claude Code,并保留排查"为什么这东西不可用"时最关键的**位置**区别:MCP 服务器**按项目**配在 `~/.claude.json`;插件装在配置目录、启用状态在 `settings.json`(装了 ≠ 启用了——这里的开关切换的是后者);技能是带 `SKILL.md` 的目录。MCP 与技能按设计只读。

## 系统

- **索引**——实时扫描进度、增量重扫、全量重建。索引是派生数据,重建不碰原始记录。
- **磁盘**——Claude Code 会在调试日志和文件历史快照里堆出数 GB。这里分类统计,清理永远先 dry-run,与运行中会话相关的文件无论如何都被排除。
- **备份**——cocopit 写过的每个配置文件,可看内容、与当前文件的差异,一键恢复(恢复本身也先备份当前内容——恢复同样可撤销)。
- **访问**——访问令牌、监听地址、允许的来源。改地址原地生效不用重启;绑定失败自动回滚。

## Codex 视图

侧栏切换器把整个控制台切到 OpenAI Codex CLI,拥有独立的 URL 空间(`/codex/*`)和独立的视觉(冷灰底 + 青色,依照 Codex 自己的 TUI 样式指南)。对齐情况:

- **仪表盘 / 项目 / 会话 / 历史**——同一套页面,读 `~/.codex` 的 rollout 记录(含 `archived_sessions`)。OpenAI 的缓存输入计价已正确拆分;费用走同一张价目表(含 gpt 系列)。
- **配额,零凭据**——Codex 把限额窗口写进每条会话记录,cocopit 显示每个账号最近一次被索引会话中的快照,并标注"数据截至"。窗口按时长分类,OpenAI 当前只发周窗口就只显示周窗口,以后恢复 5 小时窗口会自动出现。
- **账号**——通过隔离的 `CODEX_HOME` 目录实现多登录,与 `CLAUDE_CONFIG_DIR` 完全对应。登录状态(邮箱、套餐、订阅开始)从 `auth.json` 本地解码,不出服务器。
- **多 agent 运行**——子 agent 的 rollout 直接声明父线程;子会话默认从列表折叠,经父会话的"相关会话"进入,带 agent 昵称徽标。
- **扩展**——MCP 与技能只读;**插件可启停**:对 config.toml 做逐行外科手术式改写(注释原样保留),落盘前校验、写前备份。密钥类值打码,env 表不输出。
- **配置**——`config.toml` 本体保持只读(改坏影响所有会话),但 Codex 原生配置方案(`<名>.config.toml`,以 `codex --profile` 叠加)拥有**完整生命周期**:创建、编辑、删除——TOML 校验、自动备份,项目页新建会话时可直接选用。
- **终端**——以 `codex resume` 在所属账号下恢复。跨账号恢复不可行:Codex 只在自己的 `CODEX_HOME` 里找会话。

## 远程部署

1. 设置访问令牌(系统页,只能在本机操作)。
2. 把监听地址改成 `0.0.0.0`(或指定网卡)。没有令牌会被拒绝——终端等于宿主机上的 shell。
3. 反向代理/隧道后面部署时,把对外域名加进 `allowedOrigins`。

令牌只存哈希;浏览器持有签名过期的 cookie。令牌丢了,在服务器上删 `~/.cocopit/auth.json`。

## 恢复速查

| 症状 | 处理 |
| --- | --- |
| 统计数字不对 | 删 `~/.cocopit/index.db` 重启——从记录完整重建 |
| 忘了访问令牌 | 在服务器上删 `~/.cocopit/auth.json` |
| 端口被占 | 改 `~/.cocopit/config.json` 的 `port`,或删掉该文件 |
| 额度显示令牌过期 | 任意终端跑一次 `claude` |
| 终端显示已断开 | 点*重新连接*——tmux 一直留着会话 |
| 设置保存坏了 | 系统 → 备份 → 恢复写前备份 |
